# PWA と APK は何が違うのか

結論から言うと、**どちらも「スマホのホーム画面にアイコンが並び、タップすると全画面で開く」という点は同じ**です。
使っている最中は、ほとんど見分けがつきません。違うのは**配り方**と、**OS のどこまで触れるか**です。

## PWA とは何か

PWA (Progressive Web App) は、**ウェブサイトをアプリのように使えるようにしたもの**です。

普通のウェブサイトとの違いは3つだけです。

1. `manifest.webmanifest` というファイルでアプリ名とアイコンを宣言している
2. ブラウザのメニューに「アプリをインストール」が出る
3. インストールすると、アドレスバーやタブのない**全画面**で起動する

インストールと言っても、実体はブラウザが「このサイトをアプリ扱いする」と覚えるだけです。
アプリ本体はサーバーにあり、開くたびに読み込まれます（キャッシュも効きます）。

## APK とは何か

APK は **Android の正式なアプリのパッケージファイル**です。ZIP のようなもので、
アプリのコード・画像・設定がすべて詰まっています。

このアプリの APK は、Capacitor という仕組みで作ります。中身は
「画面いっぱいのブラウザ部品（WebView）を置いただけの Android アプリ」で、
そこに `app/dist` のファイルを**同梱**しています。つまり **PWA と中身は同じもの**で、
入れ物が Android アプリになっただけです。

## 並べて比較

| | PWA | APK |
|---|---|---|
| 入れ方 | Chrome で開いて「アプリをインストール」 | APK ファイルを転送してタップ |
| 提供元不明アプリの許可 | 不要 | **必要**（設定でトグルを1つON） |
| アイコン・全画面 | ○ | ○ |
| オフライン動作 | ○（このアプリは全機能が端末内で動く） | ○ |
| アプリ本体の置き場所 | サーバー | 端末内に同梱 |
| 更新のしかた | サーバーを更新するだけで全端末に反映 | APK を作り直して入れ直す |
| **サーバーがない場所でも起動できるか** | △ 初回はサーバーが要る | ○ 完全に単独で起動 |
| 作るのにかかる手間 | ゼロ（もうできている） | Android SDK か CI が要る |
| Play ストアに出す | 別途手続きが要る | できる |

## このアプリではどちらを使うべきか

**あなたの使い方なら、まず PWA で十分です。** 理由は次のとおりです。

このアプリは、どのみち**PCで同期サーバーを動かす前提**です（スマホとPCで内容を揃えるため）。
そのサーバーは、同期APIだけでなく**画面そのものも配信しています**。
つまりスマホから `http://<PCのIP>:8787` を開けば、それがもうアプリです。
PWA としてインストールすれば、以後はホーム画面のアイコンから全画面で開けます。

さらに PWA には実利があります。**アプリを直したとき、PC で `npm run build` するだけで
スマホ側にも反映されます。** APK だと毎回ビルドして入れ直しになります。
自分専用のツールを育てていく段階では、この差が効きます。

### APK のほうが向く場面

- **PCの電源が入っていない場所でスマホ単独で使いたい**とき（外出先・移動中）。
  APK はアプリ本体を端末に持っているので、サーバーが落ちていても起動できます。
  ※ただし他端末との同期は、どちらの方式でもサーバーに繋がる時だけ行われます。
- 自宅のネットワーク外から使いたいが、サーバーを公開したくないとき
- 後々 Play ストアに出したくなったとき

## PWA の入れ方（Android / Chrome）

1. PC で `npm run build && npm run server` を実行しておく
2. PC の IP アドレスを調べる（`ip addr` や `ipconfig`。例: `192.168.1.10`）
3. スマホを**同じ Wi-Fi** につなぐ
4. スマホの Chrome で `http://192.168.1.10:8787` を開く
5. 右上の「⋮」→「アプリをインストール」（または「ホーム画面に追加」）
6. ホーム画面のアイコンから起動する

> `http://` だと「アプリをインストール」が出ないことがあります。その場合は
> 「ホーム画面に追加」を選んでください。全画面表示にはなります。
> きちんと全機能を出したい場合は、Tailscale などで HTTPS にするか、APK を使ってください。
